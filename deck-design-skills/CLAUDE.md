# Правила для презентаций

Когда создаешь или правишь слайды, КП, оффер или питч (HTML, PDF, PPTX, Slides):

1. Сначала загрузи навык `presentation-design` (`skills/presentation-design/SKILL.md`) и следуй ему.
2. Не используй рамки вокруг фото, слова из отдельных букв, Inter, стекло на плоском фоне, заглушки в скобках.
3. Перед отправкой обязательно: `node tools/lint-deck.mjs deck.html`, затем `node tools/render.mjs deck.html out`, затем посмотри каждый PNG и PDF.
4. Текст: без буквы "ё", без длинного тире "—".
5. Если просьба пользователя ведет к безвкусице, предложи нормальную замену, сделай ее и коротко объясни.
