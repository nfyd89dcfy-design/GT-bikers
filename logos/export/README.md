# Знак GT — файлы

Концепт 04 «Номерная табличка», итерация 3 (хром и легкие тени, завиток G уже).

| Файл | Где использовать |
|---|---|
| `logo.svg`, `logo-*.png` | основной логотип, плоский, на светлом фоне |
| `icon.svg`, `icon-*.png` | плоская иконка: соцсети, мелкие размеры |
| `svg/gt-logo-chrome*.svg`, `png/gt-logo-chrome*` | хром: сайт, соцсети, презентации (только экран) |
| `svg/gt-logo-dark.svg` | плоский, для темного фона |
| `svg/gt-logo-mono.svg` | один цвет: вышивка, гравировка, плоттер |
| `svg/gt-logo-stacked*.svg` | вертикальный: аватар, мерч, вывеска |
| `png/gt-icon-chrome-*.png` | иконка приложения и аватар (180, 192, 512, 1024) |
| `favicon/` | favicon.ico, favicon.svg (меняет цвет под тему браузера), apple-touch-icon.png |

PNG — с прозрачным фоном, размер в имени — ширина в пикселях.
Цвета: Ink #0E1013, Frost #EEF1F4, Flare #FF4A2B. Охранное поле — половина высоты таблички.
