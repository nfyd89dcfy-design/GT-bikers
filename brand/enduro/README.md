# ТЯГА – бренд, направление Enduro

Рабочее название ТЯГА (подпись "ТЯГА GT"). Стиль: Enduro / off-road – жесткий, технический, грязь, трасса, цифры.

## Что внутри

| Путь | Содержимое |
|---|---|
| `research.md` | Выводы по референсам и конкурентам, откуда взяты палитра, шрифты, логотип |
| `naming.md` | 4 кандидата названия, риски совпадений, рекомендация |
| `logo/` | SVG: знак, горизонтальный логотип (светлый и темный фон), монохромные версии, вордмарк, фавикон, иконка приложения; `logo/png/` – превью |
| `brandbook/index.html` | Брендбук одним файлом: позиционирование, голос, логотип, цвет с расчетом контраста, шрифты, графика, фото, иконки, UI, применение |
| `tokens/tokens.css`, `tokens/tokens.json` | Дизайн-токены (цвет, шрифты, размеры, отступы, радиусы) |
| `site-mockup/index.html` | Макет главной: hero, подбор, линейка, конфигуратор, сравнение, шоурум, тест-драйв, футер |

## Как открыть

Откройте `brandbook/index.html` и `site-mockup/index.html` в браузере двойным щелчком. Сборка не нужна. Шрифты (Oswald, Onest, JetBrains Mono) подгружаются с Google Fonts; без сети подставляются запасные гарнитуры из токенов.

## Палитра

Грязь #14110C, #26211A · Кость #F6F2E9 · Пыль #E3DACB · Сигнал #D4F04A · Ржа #B93A18 · Брод #2F6F73 (полный список в брендбуке и токенах).

## Важно

- Названия моделей, цены, адреса и цифры в макетах примерные.
- Название не проверено по базам товарных знаков: см. `naming.md`.
- Знак и вордмарк нарисованы вручную в SVG; кириллическое ТЯГА в текстах набирается Oswald Bold, отдельный кириллический вордмарк не нарисован.
