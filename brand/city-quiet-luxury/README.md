# Gran Trakt (рабочее название GT): городская тихая роскошь

Полный бренд для электровелосипедов, квадроциклов, UTV и снегоходной техники. Розница и опт, Москва, Ростов-на-Дону, Краснодарский край, шоурум в Ростове.

## Что внутри

| Путь | Содержимое |
| --- | --- |
| `research.md` | Выводы по референсам и конкурентам, откуда взялись палитра, шрифты и знак |
| `naming.md` | 4 кандидата названия, риски совпадений, домены-варианты, рекомендация |
| `logo/` | SVG: знак, горизонтальные логотипы (латиница и кириллица), монохром светлый и темный, реверс, фавикон, иконка приложения. PNG-превью и `preview.html` |
| `brandbook/index.html` | Бренд-бук одним файлом: позиционирование, голос, логотип, цвет с расчетом контраста, шрифты, графика, фото, иконки, UI, применение |
| `tokens/` | `tokens.json` (источник) и `tokens.css` (переменные `--gt-*`) |
| `site-mockup/index.html` | Макет главной: герой, квиз, линейка lite/pro/ultra, конфигуратор, сравнение, шоурум и география, тест-драйв, футер |
| `qa/` | Скриншоты проверки: десктоп 1440 и мобильный 390 |

## Как открыть

Файлы самодостаточные, сервер не нужен: откройте `brandbook/index.html` и `site-mockup/index.html` в браузере двойным щелчком. Шрифты Cormorant Garamond и Golos Text подключены через Google Fonts, без интернета сработают запасные гарнитуры (Times New Roman, Arial). В макете есть небольшой встроенный скрипт для квиза и конфигуратора, без него страница остается читаемой.

## Кратко

- Название: Gran Trakt / Гран Тракт, монограмма GT внутри знака.
- Палитра: графит #1E1D1B, патина #25382F, кость #F5F1EA, известняк #E8E2D6, бронза #80582D (на темном #C9A878), камень #6B6458, песок #CFC6B6.
- Шрифты: Cormorant Garamond (заголовки), Golos Text (текст и интерфейс), обе с кириллицей и открытой лицензией.
- Названия моделей, цены и характеристики в макете примерные.

## Честные оговорки

- Название не проходило поиск по реестрам товарных знаков и проверку доменов (из рабочей среды они недоступны). Быстрый веб-поиск шумный. Известные риски: близкое по звучанию "Trakto", слово "Gran" в линейках других производителей, существующая марка GT Bicycles (голое "GT" как торговую марку не использовать).
- Из референсов просмотрена часть: 8 из ~19 картинок Aesthetic, 2 из 4 скринов сайтов, 2 из ~16 логотипов. Остальные файлы малого размера открыть как изображения через коннектор не удалось.
- Сайты конкурентов напрямую не открывались, выводы о них опираются на слайды из папки General takes и PDF с анализом рынка.
- Иллюстрации техники и схемы кадров нарисованы вручную, это не фото. Фавикон 16 px читается как буква G, перекладина T на таком размере почти сливается.
- Скриншоты сняты в Chromium с локально подставленными шрифтами, потому что доступа к Google Fonts из среды сборки не было.
