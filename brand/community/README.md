# Тропа: бренд, режим "сообщество"

Рабочее название: **Тропа / TROPA**. Электробайки, квадроциклы, UTV и снегоходы, розница и опт, шоурум в Ростове-на-Дону. Молодежь на "ты", родители на "вы".

## Что внутри

| Путь | Что это |
| --- | --- |
| `research.md` | Выводы по референсам и конкурентам (10 пунктов), с оговорками |
| `naming.md` | 4 кандидата названия, риски, домены, выбор |
| `logo/` | SVG: знак, горизонтальный логотип (светлый и темный фон), латиница, монохром, вордмарк, фавикон, иконка приложения. `logo/preview/` – PNG-превью |
| `brandbook/index.html` | Бренд-бук одним файлом: позиция, голос, логотип, цвет с расчетом контраста, шрифты, графика, фото, иконки, компоненты, применение |
| `tokens/tokens.css`, `tokens/tokens.json` | Дизайн-токены, два режима (молодежный и спокойный) |
| `site-mockup/index.html` | Макет главной: hero, квиз, линейка, конфигуратор, сравнение, шоурум и география, тест-драйв, сервис, блок для родителей, футер |
| `screenshots/` | Скриншоты бренд-бука и макета: десктоп 1440 и мобильный 390 |

## Как открыть

Это статические файлы. Откройте `brandbook/index.html` и `site-mockup/index.html` в браузере. Шрифты (Unbounded, Onest, JetBrains Mono) подгружаются с Google Fonts, без сети будут запасные гарнитуры.

Квиз и конфигуратор в макете работают на CSS без скриптов (нужен современный браузер с `:has()`).

## Палитра и шрифты

Чернила `#1B1530`, кость `#F6F1E7`, лайм `#C8F03C`, огонь `#FF5B2E` (глубокий `#C73A12`), фиолет `#7A52FF` (глубокий `#5B35E0`), сосна `#1F6B58`, туман `#E4EFE9`, сланец `#625C78`.
Unbounded (заголовки), Onest (текст), JetBrains Mono (цифры).
