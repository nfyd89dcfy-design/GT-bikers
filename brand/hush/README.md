# Hush: бренд, сайт и доска (вторая версия)

Hush – электровелосипеды, ATV, UTV, снег. Розница и опт. Москва, Ростов-на-Дону, Краснодарский край, шоурум в Ростове. Идея: тишина электромотора, спокойствие для родителей и энергия внутри. Знак: две стойки H и волна, которая затихает в линию.

## Что внутри
| Путь | Что это |
|---|---|
| `naming.md` | смысл имени, транслитерация, слоганы, риски по ТЗ, домены |
| `logo/` | SVG-знак, горизонтальный логотип, монохром светлый/темный, app-иконка, анимированный знак, PNG-превью |
| `tokens/` | `tokens.css` и `tokens.json` |
| `site/` | живой макет: `index.html` + `assets/` (работает офлайн, открывается двойным кликом) |
| `board/` | доска в духе Figma: `hush-board.html/.png/.pdf` (4800 x 5640), отдельные фреймы в `board/frames/*.png`, скриншоты сайта в `board/shots/` |
| `brandbook.pdf` | брендбук, A4 landscape, 14 страниц |

## Палитра и шрифты
Fog #E8EDEA, Paper #F5F8F6, Pine #0F1A16, Moss #4A5E54, Lichen #BFD0C2, Ember #FF4B1F, Ember ink #B53210, Violet #7C4DFF.
Unbounded (заголовки), Onest (текст), JetBrains Mono (подписи). Встроены локально через @fontsource.

## Сайт
Чистый JS без бэкенда. 3D, сборка при скролле и шейдер на Three.js, GSAP ScrollTrigger и собственном WebGL2-шейдере (пакет shaders.com недоступен из среды, эквивалент написан руками). Бандл `site/assets/hush3d.js` собирается из `site/src/hush3d.js`:

```
npm install
./build.sh
```

Функции: вход с выбором направления и привода; hero с шейдером и байком, который собирается при скролле; линейка lite / pro / ultra (цифры примерные); 3D-просмотр и AR-заглушка (прототип); 3D-тур по шоуруму (прототип); конфигуратор с пересчетом цены; квиз подбора; сравнение трех моделей; медиа (видео-плитки с раскрытием-коллажем, каналы-заглушки); корзина с оформлением; запись на тест-драйв; переключатель "ты / вы"; сервис, доставка, гарантия, байк под ключ, кастом-дизайн.

Доступность: контраст проверен для текстовых пар, видимый фокус (violet), `prefers-reduced-motion` отключает шейдер, сборку и переходы.

Честно про прототипы: 3D-модели процедурные (геометрия, не лидар), AR только описана, тур по шоуруму условная схема, фото заменены плейсхолдерами, ссылки на соцсети и адрес шоурума заглушки, платежи и отправка форм не подключены.

## Пересборка доски
```
python3 board/build_board.py
node render-board.mjs      # PNG, PDF, frames, brandbook.pdf
```
Нужен chromium (`/opt/pw-browsers/chromium`) и `playwright-core`.
