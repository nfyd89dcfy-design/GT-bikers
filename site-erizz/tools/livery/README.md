# Ливрея GT: макеты

Скрипты, которыми сделаны макеты ливреи (18.10.2026).

- `zones.py`: зоны пластика каждой модели (полигоны в координатах фото, нормализованного до ширины 1400).
- `livery.py`: ливреи `clean`, `race`, `street` и выбранная `hybrid` (Clean + Race), фото-режим и плоская схема.
- `boards.py`: доски 1920×1080 для презентации, `factory.py`: развертка для завода с размерами наклеек в мм.
- Исходники фото: студийные снимки из коммита f1c0fac (`public/products/studio/sNN.webp`), шрифты из `node_modules/@fontsource`.

Готовые доски лежат в `brand-livery/`.
