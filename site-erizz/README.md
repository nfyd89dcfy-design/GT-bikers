# E-Rizz: макет сайта

React 19, Vite, TypeScript, Tailwind v4, gsap (ScrollTrigger, SplitText, Flip), three.js.

    npm install
    npm run dev      # разработка
    npm run build    # сборка в dist

## 3D-модели байков

По умолчанию три модели (GT Base, GT Sport, GT Pro) строятся процедурно в `src/lib/bike3d.ts`:
колеса со спицами, ободами и шашками протектора, дисковые тормоза, перевернутая вилка, моноамортизатор
с пружиной, рама, маятник, батарея с ребрами, мотор, цепь, щитки, руль, седло, подножки, логотип E-RIZZ.
Материалы MeshPhysicalMaterial, окружение RoomEnvironment (PMREM), ACES, мягкие тени.

### Как подставить свои модели (например, из Tripo3D)

1. Экспортируйте модель в GLB без сжатия Draco.
2. Положите файлы в `public/models/` под именами `base.glb`, `sport.glb`, `pro.glb`
   (можно только часть: для остальных останется процедурная модель).
3. Ориентация: нос байка смотрит в +X, вверх +Y, колеса стоят на плоскости Y = 0.
   Масштаб и центровка выставляются автоматически (длина около 1,95 м), если длинная ось лежит вдоль Z,
   модель повернется сама.
4. Пересоберите (`npm run build`) или перезапустите `npm run dev`: список файлов читается при старте сборки.

Превью в корзине, сравнении, карточках и медиа рендерятся из этих же моделей в PNG.

## Прочее

- Шейдеры (BlockNoise + Grid, Marble, Chrome) и частицы написаны на WebGL/canvas вручную: пакет shaders.com требует WebGPU.
- Тон обращения (ты / вы) выбирается на первом экране и переключается в шапке.
- Цены ориентировочные, мощность и энергия целевые.
