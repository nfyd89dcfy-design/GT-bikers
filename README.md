# GT Bikers — внутренний каталог техники и экипировки

Сайт-лендинг со статичным каталогом (без сервера и базы данных): чёрно-синяя тема, фильтры по всем параметрам,
AI-поиск запросом на русском языке, поиск по фото клиента и КП в PDF по одной кнопке.

## Как открыть
Нужен обычный веб-сервер (файлы нельзя открывать двойным щелчком, иначе браузер не даст читать картинки для поиска по фото):

```bash
python3 -m http.server 8000      # затем http://localhost:8000
```

Для публикации подойдёт GitHub Pages: Settings → Pages → Deploy from a branch → ветка с этими файлами, папка `/ (root)`.
Каталог внутренний, поэтому лучше закрыть доступ (приватный репозиторий с Pages для организации либо Cloudflare Access / basic-auth на хостинге).

## Что внутри
| Путь | Назначение |
|---|---|
| `index.html`, `css/`, `js/` | сайт |
| `js/config.js` | категории, параметры (поля фильтров), контакты компании |
| `js/nl.js` | AI-поиск: превращает фразу в фильтры (работает в браузере, без ключей) |
| `js/img.js` | поиск по фото (нейросеть CLIP в браузере; без интернета — запасной режим по цветам) |
| `js/kp.js` | сборка КП в PDF (html2canvas + jsPDF) |
| `data/products.js` | каталог (генерируется) |
| `data/embeddings.js` | векторы фото для поиска по фото (генерируется) |
| `images/` | фото моделей (сжатые) |
| `tools/ingest/` | разбор прайсов и каталогов поставщиков → `data/products.js` |
| `tools/build-embeddings.mjs` | пересчёт `data/embeddings.js` |

## Как обновить каталог
1. Скачать файлы поставщиков в рабочую папку `GT_WORK/by/` (имена `<id>.pdf|xlsx|pptx`, список — `tools/ingest/*.py`).
2. `GT_WORK=… tools/ingest/run_all.sh` — перечитать все источники, убрать повторы, сжать фото, собрать `data/products.js`.
3. `cd tools && npm install && node build-embeddings.mjs` — пересчитать векторы фото.

Для каждого источника есть свой модуль в `tools/ingest/` (форматы у поставщиков разные). Каталоги, где характеристики напечатаны картинкой,
читаются OCR (RapidOCR); такие карточки помечены в `data/products.js` как `"ocr": true`, на сайте под ними стоит пометка «сверяйте с оригиналом».

## Формат записи в `data/products.js`
```js
{ id, cat, brand, name, sku, price, cur, priceNote, price2, price2Note, images: [], src, page,
  power_kw, top_speed, range_km, battery_wh, removable_battery, …,   // поля из js/config.js — это и есть фильтры
  extra: [["Подпись", "значение"], …], desc }
```
Цены записаны как в оригинальных прайсах (EXW в юанях, розница/опт в юанях для экипировки). В КП цена пересчитывается только наценкой,
пометки поставщика и оптовая цена в КП не попадают.

## Каталог из Notion
Модели, которых нет в файлах на Диске (TEYIN, SAIGE, Mengma, LVTONG, Segway и др.), берутся из экспорта базы Notion `tools/ingest/data/notion_catalog.csv` (модуль `notion_import.py`). Цен и фото в экспорте нет. Чтобы добавить фото, нужны исходные PDF-каталоги (список в карточках, поле «Источник»).

## КП (PDF)
Форма КП на сайте: клиент, менеджер, телефон, Telegram, WhatsApp, срок действия, наценка, условия оплаты и поставки, срок поставки. Цену и валюту каждой модели можно поменять прямо в корзине КП.
В PDF Telegram, WhatsApp и телефон кликабельные, рядом QR-коды. Цены пишутся по-русски (юаней, долларов, рублей, евро), итог ещё и прописью. Оформление: `css/kp.css`, шаги на последней странице: `kpSteps` в `js/config.js`.

## Как добавить модель в каталог

**Способ 1. Одна-две модели вручную (без программирования)**
1. Загрузите фото в папку `images/custom/` (на GitHub: открыть папку → Add file → Upload files). Лучше JPG до 1 МБ.
2. Откройте файл `data/custom.js` → значок карандаша (Edit).
3. Внутри квадратных скобок `[ ]` вставьте карточку по образцу из комментария в начале файла. Между карточками ставьте запятую. Обязательны `cat`, `brand`, `name`; всё остальное по желанию: цена, мощность, скорость, `images` и др.
4. Нажмите Commit changes. Через 1–2 минуты сайт обновится сам (Cloudflare пересоберёт его).
5. Поиск по фото сам подхватит новые фото (при первом поиске индексирует их, это несколько секунд).

Значения полей `cat`: `ebike-sport`, `ebike-city`, `ebike-enduro`, `moto`, `quad`, `utv`, `golf`, `car`, `snow`, `gear`, `parts`.
Любое числовое поле из `js/config.js` (power_kw, top_speed, range_km, battery_wh, weight_kg, seats, engine_cc…) автоматически превращается в фильтр и сортировку.

**Способ 2. Новые каталоги и прайсы поставщиков (десятки и сотни моделей)**
Положите файлы (PDF, Excel, PowerPoint) в папку на Google Диске и попросите Claude добавить их: он разберёт файлы, сжмёт фото, пересчитает поиск по фото и обновит сайт. Для нового формата поставщика пишется отдельный небольшой модуль в `tools/ingest/`.

**Как удалить или исправить модель**
Ручные: правка или удаление карточки в `data/custom.js`. Модели из каталогов поставщиков генерируются в `data/products.js`, их лучше править через повторный разбор источника, а не вручную.
