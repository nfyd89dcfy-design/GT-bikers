# Скиллы для брендинга GT

Ветка содержит 103 скилла rampstackco/claude-skills (MIT, версия 1.2.0, коммит 482c9bf) в `.claude/skills/`.
Claude Code подхватывает их автоматически при открытии репозитория на этой ветке.

Каталог сайта лежит в основной ветке и сюда не входит. Работа над брендом ведется в ветках `brand/*`.

Оригинал: https://github.com/rampstackco/claude-skills. Лицензия: `LICENSE-rampstack-skills`.
